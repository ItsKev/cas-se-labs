# CAS Software Engineering in the Age of AI: Cloud-Labs

Kursrepo zu den beiden Cloud-Modulen «Cloud Data Access & Processing» (Modul 1) und «Cloud-Computing, Serverless & Hyper Scaler Platforms» (Modul 2).

## Einstieg

Dieses Repo ist ein Template. **Use this template → Create a new repository** erzeugt eine eigene Kopie, in der gearbeitet wird. Dieses Repo selbst wird weder verändert noch geforkt.

Die Anleitung beginnt mit [labs/00-setup/LAB.md](labs/00-setup/LAB.md).

## Inhalt

| Ordner | Inhalt |
|---|---|
| `labs/` | ein Ordner pro Lab mit `LAB.md`, ab Lab 01 mit `start/` (Stand vor dem Lab) und `solution/` (Stand danach) |
| `.devcontainer/` | Entwicklungsumgebung (Dev Container) für Codespaces und lokal |

Die Labs werden im Unterricht freigegeben. Das Template enthält deshalb nicht von Anfang an alle Labs.

## Hinweise

- Zugangsdaten, Schlüssel, `*.tfstate`, `*.tfvars` und `local.settings.json` gehören nie ins Repo.
- Der Inhalt dieses Repos wird aus einem Arbeitsrepo veröffentlicht. Änderungen, die direkt hier erfolgen, werden überschrieben.
